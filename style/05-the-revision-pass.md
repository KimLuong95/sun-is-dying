# The Revision Pass — The Checklist Every Chapter Survives

No chapter is "done" when the draft is finished. It's done when it's been through this. Run the
passes in order — each one is a separate read, hunting one kind of problem. Trying to fix
everything at once is how things get missed.

## Pass 0 — The Navigation Hunt (can a tired reader follow it?)
- [ ] The epigraph delivers this chapter's KNOW-item plainly ([epigraph rules](07-epigraphs-and-navigation.md)).
- [ ] First half-page answers: where, when (relative to last chapter), who.
- [ ] Every plot-load-bearing fact is stated plainly **once** — subtext for feelings, plain text
  for facts.
- [ ] [Reader-knowledge ledger](../story/05-reader-knowledge-ledger.md) updated; no KNOW-item
  left to implication alone.

## Pass 1 — The Machine Hunt (catch the AI tells)
Read only for the tells in [`01-avoiding-ai-tells.md`](01-avoiding-ai-tells.md):
- [ ] Deleted every sentence that *explains* a feeling already shown.
- [ ] Broke every tidy triad and every "not just… but…".
- [ ] Narrator never named the theme.
- [ ] Em-dashes down to ~one per page; sentence lengths wildly varied.
- [ ] Killed generic smiles/eyes/breaths/nods.
- [ ] No banned phrases survived (testament, tapestry, shiver down the spine, etc.).

## Pass 2 — The Specificity Hunt
- [ ] Every vague noun/verb challenged: can it be more exact, more *this-moment*?
- [ ] At least a few concrete sensory anchors per scene (light, smell, weight, sound).
- [ ] Every metaphor is fresh and comes from a character's own world — or it's cut.

## Pass 3 — The Voice Hunt
- [ ] Cover the dialogue tags: can you still tell who's speaking? If not, fix the voices.
- [ ] Characters dodge and hint; no one says exactly what they mean unless that itself is the
  point.
- [ ] The POV character's blind spots are intact — they misread people, as real people do.

## Pass 4 — The Lore Hunt
- [ ] No paragraph stops the story to explain the world.
- [ ] Every bit of worldbuilding arrives through trouble, the senses, or an argument.
- [ ] One new concept per scene, max. Cut the rest or move it.

## Pass 5 — The Heart Hunt
- [ ] What does the POV character *want* in this scene, and what does it *cost*? If unclear, the
  scene is decoration — fix or cut it.
- [ ] One emotional beat and one plot beat, minimum.
- [ ] The chapter ends on a hook, a turn, or a dropped floor — not a tidy bow.

## Pass 6 — The Ear (the final, non-negotiable pass)
- [ ] Read the **whole chapter out loud.** Every stumble marks a broken sentence. Every place you
  get bored marks a cut. Fix them. This pass catches what all the others miss.

---

## The two questions that decide everything
When a chapter passes all six, ask:
1. **Would a stranger keep reading?** (Pace, hook, momentum.)
2. **Would they feel something they didn't choose to feel?** (Heart.)

If yes to both, ship it. If not, you know which pass to run again.
